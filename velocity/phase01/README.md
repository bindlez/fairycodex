# Velocity Phase 0–1 (isolated branch)

No production changes. This is an experimental Cloudflare Worker market adapter; live Cloudflare deployment is NOT completed. Source is deliberately read-only and no credentials are embedded. See the downloadable full project ZIP for benchmark harness, 11 tests, and opt-in client adapter. Endpoints: GET /v1/health, /v1/market/na/hot, /v1/market/na/items?category=35 (also eu). Fresh edge cache defaults to 45 s; stale 300 s returned immediately with background refresh. Cloudflare Cache API is regional and evictable, not durable global storage. Existing FairyCodex and Central Market frontends remain unchanged. Deploy manually after connecting Cloudflare with npx wrangler deploy and test against real Arsha before enabling a frontend feature flag.
